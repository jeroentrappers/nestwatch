# Open questions

Implementers record here every place where the specs are ambiguous,
incomplete or contradictory, with the interpretation they chose. The spec
owner resolves each entry by changing the specs and removing it here.

| ID | Spec section | Question | Interim choice |
|----|--------------|----------|----------------|
| NET-1 | protocol.md §3.2 | How to listen on "all interfaces (IPv4 and IPv6)" and what makes a port "unavailable". | One dual-stack `[::]` socket (`IPV6_V6ONLY` off) when possible, else separate `0.0.0.0` and `[::]` sockets on the same port (IPv6 skipped if the host has none). Any bind failure of a required socket moves to the next port. `SO_REUSEADDR` is set except on Windows. IPv4-mapped peer addresses are reported as IPv4. |
| NET-2 | protocol.md §3.3 | The HTTP fallback range 47180..47189 overlaps the HTTPS default 47181. | HTTP is bound first; HTTPS then takes the first free port from 47181 upward, so the two never collide. Both bound ports go into TXT `http`/`https`. |
| NET-3 | protocol.md §3.3 | Maximum WebSocket frame/message size is not stated. | Frames and messages above 64 KiB are rejected by the WebSocket layer (the connection fails); the session layer checks the exact 65535-byte Noise limit. Senders refuse messages above 65535 bytes locally. Ping/pong/close frames are handled by the transport and never reach the session. |
| NET-4 | protocol.md §3.3, security.md §7 | Should the station restrict which web origins may open `/lull/1`? | Yes: if an `Origin` header is present its `host[:port]` must equal the request's `Host` (case-insensitive, scheme ignored), otherwise 403. Requests without `Origin` (native clients) are accepted. Configurable for deployments behind a proxy. |
| NET-5 | protocol.md §3.3, security.md PRIV-1 | Which HTTP headers and routing rules the app server uses. | CSP `default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self'; img-src 'self' data: blob:; font-src 'self'; media-src 'self' blob:; connect-src 'self' ws://<Host> wss://<Host>; worker-src 'self' blob:; manifest-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'` (explicit ws/wss for browsers whose `'self'` misses WebSocket schemes), plus `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, COOP/CORP same-origin, a Permissions-Policy allowing only the microphone for self, and `Cache-Control: no-cache`. No HSTS (HTTP and self-signed HTTPS coexist). Only GET/HEAD; extensionless unknown paths serve `index.html` (app routes), unknown files with an extension are 404. |
| NET-6 | protocol.md §3.3 | Certificate details and fingerprint display form. | Subject CN `Lull station`; SANs exactly the names/addresses the caller passes; `notBefore` back-dated one day for clock skew, `notAfter` 3653 days after generation; key stored as PKCS#8 PEM. Fingerprint = SHA-256 of the DER certificate as upper-case hex pairs joined by `:` (as browsers show it). |
| NET-7 | protocol.md §3.4 | SRV target host name and instance name limits. | SRV host is `lull-<device_id>.local.` (does not reveal the computer's name). The display name is trimmed and truncated to 63 bytes at a character boundary (empty becomes `Lull`); conflicts are resolved by the responder as `Name (2)`. TXT changes are re-announced by re-registering the service. |
| NET-8 | protocol.md §3.4, §3.5 | Which discovered addresses a listener receives. | IPv6 link-local addresses are dropped (endpoints cannot carry a zone, PROTO-11); resolutions without any remaining address are not reported; addresses from successive resolutions of one instance are merged (at most 16), IPv4 first; an instance whose TXT becomes malformed is reported as lost. |
| NET-9 | protocol.md §3.5 | How the VPN DNS name is found. | `tailscale status --json` (on `PATH`, or the macOS app bundle binary) with a 2 s timeout; `Self.DNSName` is used when `BackendState` is `Running` or absent. Any failure means no name. |
| NET-10 | protocol.md §3.2, §3.5 | Dial behaviour for names with several addresses and the timeout scope. | Addresses are tried happy-eyeballs style (families interleaved, next attempt after 250 ms or on failure, first success wins). The timeout covers resolution and connection of one endpoint. Trying several endpoints is sequential in the caller's order. |
| NET-11 | protocol.md §8 | Backpressure for the browser WebSocket, which has no awaitable send. | `send` returns after queuing once the browser's `bufferedAmount` is at most 256 KiB, polling every 5 ms. |
